# wordpress_digitalizacion
Mi nombre es Daniel Guerrero Martín, del curso 1º DAM-A. Esta es una página web hecha con Wordpress para la asignatura de Digitalización. Los plugins usados son Astra y Elementor.

Cuando vaya a visualizar el proceso de creación de esta página, puede leer los comentarios que he añadido a los commits, en los que explico de forma un poco más extensa las modificaciones hechas en la página y los avances que se han ido haciendo con el tiempo. Para ver estos comentarios, puede pinchar directamente en la descripción del archivo cuando se encuentre dentro del repositorio o mantener el cursor encima de dicha descripción, como "SE MODIFICA EL HEADER". 

Parto del hecho de que un supuesto cliente, llamado José Tomás, me ha encargado realizar una landing page para sus cursos de formación Security Academy. Su especialidad es la ciberseguridad, hacking ético y defensa digital. 

La página poseerá un fondo oscuro con detalles en verde, gris y blanco simulando una terminal de cualquier sistema operativo tradicional.

La estructura de las secciones y contenido será el siguiente:
- Barra de navegación
- Header
- ¿En qué puedo ayudarte?: Temas disponibles en la formación
- Metodología y forma de trabajar
- Testimonios de ex-alumnos
- Empresas con las que se trabaja o colaboradoras
- Sobre mí
- Formulario de contacto
- Footer (pie de página)

Todos los enlaces, formularios y botones que se encuentran en la página funcionan correctamente y han sido testeados con éxito.
